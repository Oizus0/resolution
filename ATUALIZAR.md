# Atualizar para 1.0.3

1. Extraia o ZIP normal.
2. Copie seu conteúdo para a pasta do repositório resolution já clonado, substituindo os arquivos correspondentes. Inclua .github e os novos arquivos de src. Não crie uma subpasta adicional.
3. No GitHub Desktop, faça Commit e Push origin.
4. Aguarde a publicação na aba Actions. O manifesto continuará em https://oizus0.github.io/resolution/manifest.json.
5. Reabra a extensão ou recarregue a sala para carregar os arquivos novos.

Não é necessário reiniciar o combate para atualizar: o formato dos dados anteriores foi mantido. A nova opção Mostrar imagens dos personagens começa ativada e fica nas configurações. Sua alteração vale para toda a mesa.

Este pacote contém o código-fonte e o workflow de publicação. Não foi enviado automaticamente ao GitHub. As imagens usadas na prévia são tokens de teste; na sala, são usadas as imagens dos seus próprios tokens.
